# 视频脚本：让大肥鱼记住你

B 站横屏，约 5 分 50 秒。全程由大肥鱼娘（女仆形象）出镜串场，演示部分走录屏。

> 本版新增两段：**镜头 9 · 从 SurfCore 搬过来**（一键迁移）、**镜头 12 · 它会睡觉**（睡前整理）。如果时长要压回 5 分钟以内，这两段都可整段剪掉，不影响主线。

**标题备选**

- 上下文 1M 了，为什么你的 AI 还是不认识你
- 让你的大肥鱼，记住你三年
- 四个不限：换个模型、换台电脑，它还记得你

**核心口号**（全片反复出现的字幕卡）

> 不限会话 · 不限 agent · 不限模型 · 不限设备

**一句话定位**：上下文再大也是一次性的，记忆得存在你自己这儿。

## 拍摄前置

**形象**：大肥鱼娘立绘 / PNGtuber，深蓝女仆装。准备三种状态——全屏（开场收尾）、右下角画中画（讲原理时）、小窗（纯录屏时压到角落）。

**数据**：一定要先灌演示库，空库录出来很难看。

```bash
npm run seed:demo
SQLITE_PATH=./data/demo.db npm start
```

**画面**：终端字号 18 以上，浏览器缩放 125%，关通知，桌面只留终端和浏览器。

>
> 所以真正要解决的不是"装得下"，是"**想得起**"。

**字幕**：不是装得下，是想得起

## 镜头 4 · 四个不限（1:20 - 1:50）

**画面**：形象回到全屏。四个词依次弹出，每个配一个快速切换的画面：新会话窗口 / Cursor 和 DSH 的图标 / DeepSeek 与其他模型的标识 / 笔记本和手机。

**口播**：

> 这就是 MemLattice 想干的事。一句话概括，**四个不限**。
>
> **不限会话。** 今天聊完关掉，下个月再来，它还记得。
>
> **不限 agent。** 你在 Cursor 里说过的话，DSH 里也能用，Claude Code 里也能用——因为记忆不在客户端里。
>
> **不限模型。** 今天用大肥鱼，明天换别的模型，记忆是同一份，谁都读得到。
>
> **不限设备。** 数据是本地一个文件，台式机拷到笔记本，接着用。
>
> 记忆属于你，不属于某个会话、某个客户端、某个模型。

**字幕**：记忆属于你，不属于任何一个客户端

## 镜头 5 · 原理一：CPU 缓存（1:50 - 2:20）

**画面**：形象画中画。主画面是简化的 CPU 层级图——寄存器、L1、L2、L3、内存，从左到右越变越大、越变越慢。动画表现数据从左往右"下沉"。

**口播**：

> 这套思路，计算机几十年前就在用了，叫缓存。
>
> CPU 旁边有一层一层的小仓库。最快最小的那个只能放几十个数，但几乎不用等；越往外越大、越慢、越便宜。
>
> 原理一句话：**常用的放最近，不用的往下沉。**
>
> 你不需要每次都读一遍整个硬盘，你只需要把此刻要用的那几页，放在手边。

**字幕**：常用放近处，不用的往下沉

**画面**：录屏 + 画中画。依次点开三个页面：常驻层、卡片列表、某张卡的原始对话。

**口播**：

>
> 关键在最后一句：**每一轮只往上翻该翻的那几页。**

**字幕**：便利贴 · 笔记本 · 纸箱

## 镜头 9 · 从 SurfCore 搬过来（3:50 - 4:20）

**画面**：录屏。DSH 会话里输入 `/memlattice SURFCORE迁移`，回车；弹出权限确认，鼠标点「完全权限」；接着是一串自动执行的输出（读角色包 → 分类 → 写库），最后停在「人格 1 张 · 记忆 4 条 · 规则 7 段 · 技能 6 段」。

**口播**：

> 如果你是 SurfCore 的老用户，恭喜，这一步能省掉所有手工活。
>
> 装完之后，在会话里敲一行：斜杠 memlattice，空格，SurfCore 迁移。
>
> 权限得开到「完全」——它要读你的角色包、要写数据库，中间权限不够就会停在半路。
>
> 然后它自己就开始搬了：人格卡读出来放第一层，记忆记录一条条变成卡片，那套提示词按段切开——行为规则进规则块，工具手册进技能块，每轮都在变的状态直接丢掉。
>
> **原来的东西一个都不动**，它只是复制了一份过来。想退回去，一条命令还原。

**字幕**：`/memlattice SURFCORE迁移` · 一次搬完，原样保留

**画面细节**：

- `/memlattice SURFCORE迁移` 要完整露出，这是全片唯一的"命令式"操作，观众会截图
- 权限弹窗停留 2 秒以上，让观众看清是「完全权限」
- 输出结果那屏停 3 秒，四条数字是最有说服力的画面
- 别在录屏里露出角色包路径里的真实 QQ 号

## 常见翻车点

- **空库录制**：不跑 `seed:demo` 就录，图谱只有几个点，列表空荡，说服力为零。
- **现场打字**：命令提前敲好，用上箭头调历史。
- **术语漏嘴**：口播里不要出现「向量」「PPR」「embedding」「MCP 协议」，出现一次走一批人。「MCP」只在配置那一镜的画面里出现，不念出来。
- **别再说"上下文不够"**：这是这一版最容易翻的旧观念。现在各家上下文都在 1M 上下，说"不够用"会被弹幕打脸。要打的是「带不走」，不是「装不下」。
- **迁移那段别露真实账号**：角色包里带着 QQ 号、B 站 UID、会话令牌。录屏前先把窗口缩到只露出分类结果那几行，或者用一个干净的演示角色包。
- **权限弹窗别演假的**：镜头 9 那次要真点「完全权限」。演示「部分权限 → 报错 → 再改」（翻车点 302 行说的那种）会让观众以为流程很麻烦。
- **数字别念死**：演示时注入量会浮动，念"两三百个 token"比念"1200"稳。
- **许可要提**：说出来显得坦荡，也避免有人拿去做商业产品后反咬。
