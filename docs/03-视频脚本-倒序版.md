# 视频脚本 V2 · 倒序版：先说它能干什么

B 站横屏，目标 4 分 20 秒。**顺序改成：能力 → 原理 → 动机。**

> 上一版是"痛点开场 → 原理 → 能力"，观众得等两分钟才看到结果。这一版反过来：前 20 秒就把最炸的能力砸出来，让人先"哇"，再听你解释为什么能做到。

**标题备选**

- 重磅：GitHub 上这个新开源项目，让 AI 真正记住你
- 它记住我三年：跨会话、跨客户端、跨模型
- 上下文是租来的，记忆才是你的

**核心口号**（全片反复出现的字幕卡）

> 不限会话 · 不限 agent · 不限模型 · 不限设备

**一句话定位**：上下文再大也是一次性的，记忆得存在你自己这儿。

**语气基调**：元气、兴奋、语速偏快（6 字/秒左右），像刚发现一个好东西急着告诉朋友。少用"我们将""本文"，多用"你看""注意看""就这么简单"。

## 镜头 1 · 重磅开场（0:00 - 0:18）

**画面**：黑底。第 0 秒，白色大字「重磅」从上砸下，屏幕轻微震一下；1.2 秒切到项目名 `MemLattice` 发光定格；第 3 秒切到她（全身，右下角弹入），元气地朝镜头挥手。

**口播**：

> 重磅消息——GitHub 上刚开源了一个项目，叫 MemLattice。
>
> 它干了一件所有人都在等的事：**让 AI 真正记住你**。
>
> 不是记住这一次，是记住你这个人。

**字幕**：让 AI 真正记住你

## 镜头 2 · 三个「任何」（0:18 - 0:55）

**画面**：全屏录屏。新开一个空会话，**什么都不解释**，直接连问三句。每问一句，答案逐字出现，旁边弹出绿色对勾。

**口播**：

> 注意看，我现在开的是一个**全新的会话**，一个字都没提。
>
> 第一句：我的作息和开会习惯，你还记得吗？
>
> 它说：十点之前你还没进入状态，急事发消息，别打电话。
>
> 第二句：我喝咖啡什么口味？
>
> 它说：浅烘手冲，不加糖不加奶，怕苦。
>
> 第三句：数据库选型最后定的什么？
>
> 它说：默认 SQLite 单文件，要分区表或者向量检索，配个连接串切 PostgreSQL。
>
> 全对。**这些不是它猜的，是你以前说过、它记下来的。**

**字幕**：新会话 · 什么都不用解释

**画面细节**：第三个答案答完后停 1 秒，让观众有"它真记得"的余味；右下角可以飘一行小字，标这一轮只用了多少 token。

## 镜头 3 · 四个「不限」（0:55 - 1:30）

**画面**：回到她（画中画，右下角）。四个词依次砸在画面中央，每个词配一个快速切换的画面：新会话窗口 / Cursor 与 DSH 的图标 / 模型列表 / 笔记本和手机。

**口播**：

> 一句话概括，**四个不限**。
>
> **不限会话**——今天聊完关掉，下个月再来，它还记得。
>
> **不限 agent**——你在 Cursor 里说的话，DSH 能用，Claude Code 也能用。因为记忆根本不在客户端里。
>
> **不限模型**——今天用这个，明天换那个，记忆是同一份，谁都读得到。
>
> **不限设备**——数据就是你本地的一个文件，台式机拷到笔记本，接着用。
>
> 记忆属于你。**不属于某个会话，不属于某个客户端，也不属于某个模型。**

**字幕**：记忆属于你，不属于任何一个客户端

## 镜头 4 · 那它怎么做到的：三层（1:30 - 2:25）

**画面**：录屏 + 画中画。依次点开三个页面：常驻层、卡片列表、某张卡背后的原始对话。每切一个页面，画面右下角浮出对应的"实物"图标：便利贴 / 笔记本 / 纸箱。

**口播**：

> 好，那它到底怎么做到的？分三层，用三个东西打比方，一秒就懂。
>
> **第一层，贴在显示器边上的便利贴。** 只有几行——你是谁、有什么规矩、哪些经验绝不能忘。每次对话开头，它一定被看见。
>
> **第二层，抽屉里的笔记本。** 每件事一页，只写结论，不写过程。要用的时候翻两页，不用就合上。
>
> **第三层，储物间的纸箱。** 原始聊天记录，一箱一箱码着。只有要查"当时到底怎么说的"，才去翻。
>
> 关键在最后一句：**每一轮，只往上翻该翻的那几页。**

**字幕**：便利贴 · 笔记本 · 纸箱

## 镜头 5 · 热度：它会自己整理（2:25 - 3:00）

**画面**：录屏，设置页。鼠标把「卡片热度半衰期」从 30 拖到 45。随后切到她（画中画），打了个小哈欠。

**口播**：

> 而且它像人一样，**会忘**。
>
> 天天用到的事，热度高，一直在手边；久不碰的，被压成一句话摘要，原文收进归档；再不用的，进回收站，七天之内还能捞回来。
>
> 多久算久，**你自己定**。这里每个数字都能改，改完立刻生效，不用重启。
>
> 会忘，才装得下新的。

**字幕**：会忘，才装得下新的

## 镜头 6 · 这套思路从哪来（3:00 - 3:25）

**画面**：她回到全屏。主画面左侧浮出 CPU 层级图（寄存器 / L1 / L2 / L3 / 内存），一条光带从左往右"下沉"。

**口播**：

> 这套思路不是拍脑袋想出来的，计算机几十年前就在用了，叫缓存。
>
> 最快最小的那层只能放几十个数，但几乎不用等；越往外越大、越慢、越便宜。
>
> 原理一句话：**常用的放最近，不用的往下沉。**
>
> 你不需要每次都读一遍整个硬盘，你只需要把此刻要用的那几页，放在手边。

**字幕**：常用放近处，不用的往下沉

## 镜头 7 · 那为什么非做不可（3:25 - 4:00）

**画面**：她全屏，表情从兴奋转成认真。背景画面：左侧是"聊了一晚上的对话"，右侧是空白新会话，中间一条红线切开——然后左边的对话整个熄灭。

**口播**：

> 那问题来了：这么简单的道理，为什么以前没人给你？
>

>

> 不是你记错，是它根本没打算留。
>
> 所以我们做了 MemLattice：**把该记的存下来，把该想起来的递过去，把该忘的放掉。**
>
> 记忆这件事，本该由你自己保管。

**字幕**：上下文是租的，记忆才是你的

## 为什么这么排（给自己看的）

1. **前 20 秒定生死。** B 站完播率就看前三秒，"重磅 + 项目名"给的是信息，不是悬念；第 18 秒已经看到"新会话直接答对三题"，用的是结果，不是承诺。
2. **原理放在能力之后。** 观众先"哇"，才有耐心听你讲三层结构；反过来，先讲原理等于让人先看你上课。
3. **动机放最后，才有力量。** "上下文是租的"这句是情绪落点，放在能力被证明之后说，观众才会信。放开头就是抱怨，放结尾就是洞察。
4. **每 40 秒一个"炸点"。** 三个任何（0:18）→ 四个不限（0:55）→ 三层比喻（1:30）→ 会忘（2:25）→ 缓存（3:00）→ 租的（3:25）→ 三条命令（4:00）。密度靠这个撑，不靠 BGM 撑。

## 和旧版的差别

| | 旧版 | 这版 |
|---|---|---|
| 开头 | "你有没有过这种事"——痛点共鸣 | "重磅消息"——直接给结论 |
| 能力位置 | 第 1:20 才出现 | 0:18 就演示完 |
| 原理 | 第 1:50 起，占了 1 分半 | 压缩到 1 分钟以内，比喻为主 |
| 动机 | 散在开头 | 集中到 3:25，作为情绪高潮 |
| 时长 | 5:50 | 4:20 |

## 录制清单（画面侧）

- 演示库必须先灌数据：`npm run seed:demo`，再 `SQLITE_PATH=./data/demo.db npm start`；空库录出来没有说服力。
- 镜头 2 那三问的答案必须真实来自库里，不能念稿——观众看得出停顿。
- 终端字号 18 以上，浏览器缩放 125%，关通知，桌面只留终端和浏览器。
- 镜头 7 左侧那段对话，建议用真实用过的内容（打码后的），比造的好。
